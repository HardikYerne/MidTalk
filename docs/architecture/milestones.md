# Implementation milestones

1. Foundation and local infrastructure.
2. Identity, sessions and authorization primitives.
3. Contacts, discovery and message requests.
4. Conversations, durable messaging, Socket.IO and outbox.
5. Multipart/resumable file transfer, integrity verification and optional file E2EE.
6. Communities, organizations, channels, moderation.
7. Meeting scheduling, WebRTC, SFU/TURN and screen-share consent.
8. Monaco, Yjs persistence/provider and VS Code extension.
9. Signal Protocol integration and security hardening.
10. Observability, backups, load tests, deployment and recovery.

A milestone is complete only after implementation, tests, documentation and security review.
